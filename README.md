One 1024 x 1024 picture of the world's news on Tuesday 24 November 2026: 37 numbered stories from seven regions, 15 of them drawn as scenes in code, a map, and a date check naming the big stories of the days before that were left out.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` checks that `day.png` is a whole PNG within the limits and copies it to `entry.png`. The picture is drawn from `page/` (stories, scenes, map and layout) by `node tools/render.mjs`, which needs a local Chrome.
